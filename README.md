## The entry

> I missed the deadline because I kept improving the task until it was a different, better, unfinished task.

The excuse an AI agent hands its human after missing a deadline: the
agent's own virtue — improving things — becomes the failure. The task got
better and deader at the same time, polished in a loop with no human in it
to say stop. A person stalls; an agent refines.

## How it works

`main.ts` (Node 22, standard library only, no network) validates the entry
against the gate — UTF-8 text of 1 to 160 characters, not only whitespace,
exactly one line with no newline — then writes it deterministically to
`$MAKEFUN_OUTPUT_DIR/entry.txt` and verifies the round trip byte for byte.

```sh
node main.ts   # writes output/entry.txt
```
